HERM

Политика обработки данных

Описание личного приложения Herm и его подключения к Google Workspace.

Какие данные доступны

В пределах выданных Google-разрешений приложение может получать письма и их содержимое, сведения о календарях и событиях, файлы и документы Google Drive, содержимое Google Docs и Sheets, а также контакты. Приложение использует данные для задач владельца: поиска, чтения, подготовки сводок и согласованных изменений.

Как обрабатываются данные

Google Workspace CLI обращается к Google API. Локальный Hermes обрабатывает выбранные данные. Текст, необходимый для выполнения запроса, может передаваться настроенному владельцем поставщику ИИ; конкретный поставщик зависит от текущей конфигурации. Передача в другие инструменты и сервисы зависит от поручения владельца и используемого рабочего процесса.

Основной ИИ-маршрут на дату обновления — OpenAI через учётную запись ChatGPT. Условия обработки и хранения у поставщика определяются его политикой и настройками этой учётной записи. Приложение не устанавливает единый срок хранения для внешних сервисов и не гарантирует, что все данные остаются только на компьютере. При смене поставщика владелец должен проверить его условия перед передачей данных.

Хранение

Учётные данные OAuth хранятся на компьютере владельца и не включаются в страницы сайта. Выдержки из документов и писем могут сохраняться в локальных результатах задач, истории помощника, отчётах и резервных копиях. Единого автоматического срока удаления для этих материалов сейчас не установлено.

Отключение и удаление

Владелец может отозвать доступ Herm в настройках подключений Google и отключить локальные задания. Отзыв доступа прекращает будущие обращения через отозванные учётные данные, но сам по себе не удаляет ранее сохранённые результаты, историю и резервные копии. Их удаление выполняется отдельно владельцем.

Этот сайт

Информационные страницы размещены на GitHub Pages. В них нет форм входа, OAuth-токенов, содержимого почты, документов, рекламных или аналитических скриптов. При посещении сайта GitHub обрабатывает технические сведения о запросах по своей политике конфиденциальности. Сайт не выполняет подключение к Google API.
